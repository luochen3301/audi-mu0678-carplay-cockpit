# 安装指南

适用：Audi MHI2，固件 `MHI2_ER_AUG22_P3241`，MU0678，带虚拟座舱，有线 CarPlay 正常。其他固件请不要使用（脚本也会拒绝）。

所有脚本都通过 M.I.B. 的绿色工程菜单运行：**m.i.b → Advanced Settings → Run individual script**，
它运行的是 SD 卡上的 `mod/command.sh`。`command.sh` 根据 `mod/RUN` 文件里的一个词决定运行哪个包：

| `mod/RUN` | 运行 | 会不会改车机 |
|---|---|---|
| 没有这个文件 / `altscreen` | `mod/custom.sh`（CarPlay 地图安装器） | 按 `mod/altscreen/ACTION` |
| `navignore-collect` | `mod/navignore/collect.sh` | 不会（只读） |
| `navignore` | `mod/navignore/navignore.sh`（双导航安装器） | 按 `mod/navignore/ACTION` |
| `zoom-collect` | `mod/zoom/collect.sh` | 不会（只读） |

`ACTION` 文件里写 `install`、`uninstall` 或 `logs`（默认 `logs`，只导出日志）。已经装好时 `install` 也只导出日志。
每次运行的日志在 SD 卡的 `altscreen_logs/`、`navignore_logs/`、`zoom_logs/` 下，按 001、002…… 编号。

> 编辑 `RUN`、`ACTION` 时用会保留 LF 换行的编辑器；脚本能容忍 CRLF，但 `.sh` 文件本身必须是 LF（`.gitattributes` 已保证）。

## 0. 准备 SD 卡和 M.I.B.

1. 全尺寸 SD 卡，FAT32。有些卡车机读不出来，换一张即可（实测 2 GB 小卡可用）。
2. 把 M.I.B. V3.6.0 全部解压到卡的根目录，插 **SD1**。
3. 红色菜单 → Software Update → SD 卡 → 选 **M.I.B. Launcher** → 开始。车机会重启几次，中途不要拔卡、断电。
   出现版本比较提示时选 Cancel。
4. 之后用绿色菜单进入 M.I.B.。组合键因车型而异；在作者测试的 A4 B9 上：
   - **绿色菜单**：左右两个方向盘拨杆**同时往上**按住几秒；
   - **红色菜单**：**左拨杆往上 + 右拨杆往下**。
5. 建议先用 M.I.B. 做一次基本备份（EEPROM 等），备份只保存在你自己的电脑上。

## 1. 只读收集（第一次必须做）

1. 把 `sd-collect/mod/` 里的 `command.sh`、`custom.sh` 拷进卡上的 `mod/`（覆盖 M.I.B. 的示例文件）。
2. 车上运行 **Run individual script**，等它显示 `Nothing on the unit was changed.`。
3. 把卡上 `altscreen_collect/001` 拷到电脑的 `car-data/altscreen_collect/001`，运行：

   ```bash
   python tools/check_collect.py car-data/altscreen_collect/001
   ```

   全部 PASS 才继续。`libairplay.so` 不一致说明固件不同，本套件不能用。

## 2. 安装 CarPlay 仪表地图

1. 按 README 的命令生成 `build/sd/`（会核对原作者文件和你原厂配置的 SHA-256）。
2. 把 `build/sd/mod/` 的内容拷进卡上的 `mod/`；`mod/altscreen/ACTION` 默认是 `install`。
   卡上没有 `mod/RUN`（或写 `altscreen`）。
3. 车上：点火档打开、发动机不启动、**手机先不插** → Run individual script。
4. 屏幕依次显示检查结果、`installed ...`、`INSTALL COMPLETE.`，30 秒后自动重启。中途出现 `!! STOPPED` 时，
   最后几行会说明车机现在的状态（大多数情况是"什么都没改"）。
5. 测试：插手机，中控 CarPlay 正常；仪表切到地图页，出现 CarPlay 地图。

**从 v1 升级到 v1.1**：用同样的方式运行即可，屏幕会显示 `older version, will be upgraded`，只替换 hook，不再改 CarPlay 配置。

**卸载**：把 `mod/altscreen/ACTION` 改成 `uninstall` 再运行。它先放回原厂配置（校验一致），再删掉装上的文件，然后重启。

## 3. 双导航（开导航时仪表保持 CarPlay 地图）

1. 卡上 `mod/RUN` 写 `navignore-collect`，把仓库的 `src-sd/command.sh` 和 `src-sd/navignore/` 拷到卡上，车上运行一次
   （会复制 58 MB 的 `/ifs/lsd.jxe`，要等 1～3 分钟）。
2. 把 `navignore_logs/001-collect` 拷到 `car-data/navignore_collect/001`；把你 M.I.B. 卡上的 `mod/java/navignore_audi.jar`
   拷到 `inputs/navignore/`。
3. 生成安装包（会先用 `tools/jxe/check_override.py` 把 jar 里的两个类和你车上的原厂类逐成员核对，不通过就拒绝）：

   ```bash
   C=car-data/navignore_collect/001
   python tools/build_navignore_package.py --jar inputs/navignore/navignore_audi.jar \
       --lsdsh $C/files/mnt__app__eso__hmi__lsd__lsd.sh --jxe $C/files/ifs__lsd.jxe \
       --listing $C/cmd/ls_lsd.txt --src-sd src-sd --out build/sd-navignore
   ```

4. 把 `build/sd-navignore/mod/` 拷进卡上的 `mod/`（其中 `RUN` 为 `navignore`，`ACTION` 为 `install`），车上运行。
5. 测试：CarPlay 开始导航后仪表保持 CarPlay 地图；Siri（长按语音键）、CarPlay 通话、音乐、导航语音正常。

**卸载**（任选其一）：
- 车上：绿色菜单 → **m.i.b → navigation → NavActiveIgnore → Remove dual navigation**（不需要电脑）；
- 或把 `mod/navignore/ACTION` 改成 `uninstall` 再运行。

**注意**：先开车机自带导航、再开 CarPlay 导航时两者会同时导航；反过来 CarPlay 导航会被停掉。
仪表底部的海拔/路名/比例尺条去不掉。

## 升级车机固件之前

先卸载双导航和 CarPlay 地图。固件变了以后安装器会拒绝安装，但已经装上的文件不会自动消失。

## 风险

- 最坏情况：车机界面（HMI）起不来，菜单无法使用，需要 USB 网卡接入或专业店用诊断仪重刷固件才能恢复。
  安装器的检查和测试就是为了避免这种情况，但不能保证为零。
- 详见 [safety.md](safety.md) 和 [findings.md](findings.md)。
